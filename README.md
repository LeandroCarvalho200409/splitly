# Splitly | Expense splitting helper for groups

Ever gone on vacation with friends, or worked on a group project where expenses need to be tracked and shared fairly? **Splitly** is a web application designed for exactly that. 

- **Backend** Express.js
- **Frontend** React

With Splitly, you can:
- Track who paid what
- Split expenses evenly or by custom percentages/ amounts
- Handle different currencies and payment methods
- Keep everything organized in one place

🚧 This project is still in progress. ⚠️
